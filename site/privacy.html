Privacy Policy

Vice Cartel Uploader is used only by the channel owner. It uses Google OAuth solely to upload videos and set their titles, descriptions and tags on the owner's own YouTube channel. It does not collect, sell or share any personal data, and it does not access any other user's data. OAuth credentials are stored encrypted as GitHub repository secrets and are used only for these uploads. The owner can revoke access at any time at https://myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
